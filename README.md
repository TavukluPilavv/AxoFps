# AxoFPS

A client-side Fabric mod for Minecraft Java Edition 1.21.1.

## Build
Run:
```bash
gradle build
```

The JAR is generated in `build/libs`.

## Controls
- Right Ctrl: open AxoFPS settings
- Performance profile: toggles minimal particles and clouds off
- Particles and clouds can be adjusted separately

Requires Java 21, Fabric Loader, and Fabric API.
