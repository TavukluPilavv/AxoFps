# AxoShader (Iris 1.21.1)

This folder contains an **early shader-pack prototype** for Minecraft Java 1.21.1 with Iris.

## Features being developed
- Warm sunlight and color grading
- Leaf/vegetation wind animation
- Entity/player shadow pass
- Water highlights and subtle animated UVs

## Status
Prototype only. It has not yet been tested in-game or validated against Iris's shader compiler. The initial shader files are experimental and may need compatibility adjustments.

## Build/install
Shader packs are ZIP folders, not Fabric mods. Package the contents of this directory so the ZIP root contains `shaders/` and `pack.mcmeta`, then put the ZIP in `.minecraft/shaderpacks/` and select it from Iris.

## Target
Minecraft Java 1.21.1 + Iris Shaders.
